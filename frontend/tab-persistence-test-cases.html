Tab Persistence Test Cases

Covers the fix where switching tabs (Assistant / Smart Order / Warranty / Metrics) used to destroy the page you left, wiping any typed-but-unsent text and the whole conversation. Tabs now stay mounted and only show or hide, so state should survive switching away and back. No automated frontend runner is wired up yet (just tsc + vite), so these are run by hand against npm run dev.
